# jiucai-box

随机一只匿名美股、随机一段历史，完成 60 个交易日的模拟操作。纯前端，打开浏览器即可使用，没有后端、数据库、账号或存档功能；刷新页面会随机新开一局。

- 日线 K 线、MA5/10/20、成交量与均量线、MACD（12/26/9）。
- 长按选中 K 线，滑动查看开高低收和联动指标；电脑支持鼠标与方向键。
- K 线支持放大、缩小、复位及双指缩放，显示最近 12–70 根已揭示日线，成交量和 MACD 同步。键盘支持 + / - / 0。
- 快捷多空仓位 25% / 50% / 100%，可自定目标仓位或平仓。
- 30 只股票，每只 250 根日线，共 3,930 个股票与起点组合。
- 收盘后下单，下一交易日开盘成交；60 天结束后显示收益和回撤。

## 本地运行

需要 Python 3（提供本地静态服务）及 Node.js 22 或更高版本（运行测试）。没有需要安装的 npm 依赖。

```sh
npm run dev
# 打开 http://127.0.0.1:8765/
npm test
```

直接双击 `dist/index.html` 会受到浏览器读取 JSON 的限制。需要单文件离线版时运行：

```sh
npm run bundle
# 用浏览器打开生成的 jiucai-box.html
```

## 行情样本

样本时间为 **2025-01-02 至 2025-12-31**，来源为 Yahoo Finance 历史 chart 接口。30 只股票为：

`AAPL MSFT AMZN TSLA GOOGL META NVDA AMD INTC QCOM AVGO ORCL CRM ADBE JPM BAC GS V MA XOM CVX JNJ PFE UNH LLY KO PEP WMT COST DIS`

另保留 SPY 供早期计算实验使用，不进入随机股票池。数据已缓存至 `dist/data/us-2025.json`，网站运行和正常 CI 发布不调用行情供应商。取数脚本默认仅补齐缺失股票；显式更新全部历史：

```sh
python scripts/fetch_data.py --refresh
npm test
```

取数时校验交易日期一致性、OHLC 关系、有限数值和成交量，拒绝样本期内有拆股的股票。当前样本不含样本期内拆股，不做分红复权；分红通过交易引擎单独记账。行情可能有供应商修订，不等同于交易所审计数据。

本项目用于个人模拟练习。行情为第三方数据，未取得独立的商业再分发授权；不要把代码仓库公开误认为获得了数据商业授权。原始来源地址和响应哈希随样本保存。

## 撮合约定

- 初始资金 100,000 美元。至少 60 根前置日线供观察，随后交易 60 个交易日。
- 目标仓位在 −100% 至 +100%，预留交易费用后取整股；未下单则保持原股数。
- 佣金 0.10%，不利滑点 0.05%，空头借券年费 5%（按自然日）。这些是模拟参数。
- 除息日按隔夜持仓计分红：多头获得、空头补偿，不模拟实际派息日或税费。
- 净资产 / 总敞口低于 50% 触发模拟风控。开盘触发立即平仓，收盘触发下一开盘处理；不模拟盘中强平。
- 假设所有股票都能借券，没有真实券源、召回或流动性限制。期末以收盘价计净值，不假设已卖出。
- 所有指标只用已揭示数据。MACD 柱为 `2 × (DIF − DEA)`，EMA 用首个完整周期均值初始化。

匿名仅是界面功能：姓名、股票代码和真实日期不显示，但纯前端行情可从文件查看，无法提供防作弊或隐藏未来数据的保证。没有登录、排名和跨设备同步。
